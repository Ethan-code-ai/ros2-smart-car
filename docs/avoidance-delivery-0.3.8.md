## 控制逻辑修复

选路前缀、直线执行和恢复前进共用方向相关的平移检查，取消选路起点无条件要求整圈安全的入口。已知障碍继续参与全部候选轨迹，执行转向仍检查其扫过包络。选得出方向不代表无条件批准旋转；后方近障会在转向执行检查中单独报告。

新增 `blocking_point_m` 与 `coverage`，状态和安全拦截记录保留具体触发点及动作类别；前端共享避障设置显示当前触发点的车体坐标。净空字段改为相对物理包络计算，不再以“截断为零后加 0.15 m”的方式产生误导性的固定 15 cm。触发判定保留原保护距离政策，不通过缩小余量掩盖问题。

新增回归验证云图与 TF 点位一致、后方近障不一律否决选边但仍限制转向、相交净空应为零。原闭环避障、未知扫描、停止/跟随失效与 ROS 适配回归保留。
