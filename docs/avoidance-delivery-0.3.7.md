# 0.3.7 优化与实车诊断记录

2026-10-28。本版本继续执行主动避障优化计划；软件与部署有进展，实车绕行验收仍未通过，不宣告整份计划完成。

## 本轮修复

1. 查明车端实际 `sllidar_node.cpp` 含有硬编码：把原始角度 90°～270° 的回波强制写成正无穷。独立复制并编译完整扫描驱动，仅去除该角度屏蔽；零距离仍作为未知，不把无穷填成空地。原厂驱动与源码未覆盖。
2. 选路改为检查约 0.20 m 的可观测安全前缀，后续路径交由每周期防撞检查；未来已知障碍仍参与候选剔除。远期路径未知不再单独否定起始安全前缀。
3. 直线平移允许远离后方近障；只有障碍一直位于运动后方、距离不减小时才能适用。转向不使用该例外，不能借此倒车或旋转接近障碍。
4. 平移可见性改为射线与轨迹包络求交，扩大一条射线间距覆盖未知角度缝隙；有限回波后方仍为遮挡区域。只排除车辆已占据的物理区域，不把安全余量当成已知空地。边界扇区覆盖不足仍可保守停车。

恢复完整扫描后，有效有限回波从约 500 增至约 890～908。用户已将后方包挪开，并人工向前移动整车约 10～20 cm；约 6 cm 的后方近回波仍存在，不能继续直接归因于包。它可能来自车身遮挡、安装坐标或模型差异，尚未完成物理确认，不做大范围过滤。

车身 CAD 与扫描高度 0.11 m 相交的结构位于车体后方约 0.105～0.160 m；实际最近回波更靠前，说明现有模型不足以直接支持精确自反射过滤。须核对真实安装和扫描平面，不能只按 CAD 外接框删点。
