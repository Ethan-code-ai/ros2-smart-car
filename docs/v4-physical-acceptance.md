# v4.0.0 实车验收登记

能力放行使用独立的实车验收记录。主机将当前车辆、车端源码构建、地图和视觉模型纳入能力指纹，每个能力分别验收。车端代码支持、当前就绪和实车通过是三个独立状态。

登记要求 `robots.manage`、`robots.read` 和 `robots.control`。普通操作员可查看能力和验收记录，管理员登记或撤销证据。模型工具没有登记入口。

## 操作流程

1. 在现场完成相应能力的试验，保存运行日志、测量结果和实际控制发布者记录。
2. 车辆停稳后，请求 `GET /api/v1/robots/{robot_id}/acceptance-template?capability=navigate`。其他能力可选 `patrol`、`deliver`、`observe_target`、`patrol_search`。
3. 按实际结果填写模板。检查项初始均为 false，时间、文件摘要和测量值需由验收人补全。artifact 的 name 是留存证据文件名，sha256 是对应文件内容摘要。
4. 将完成的模板提交到 `POST /api/v1/robots/{robot_id}/acceptances`。主机复核新鲜静止里程计、当前版本指纹、检查项和性能门槛，保存规范化证据及审计记录。
5. 用能力接口核对 accepted 与 executable，并将返回的验收 ID 附入实车记录。

相同 request_id 和相同证据可重复提交。改变证据需使用新的 request_id。登记后证据保持原样，可通过 `GET /api/v1/robots/{robot_id}/acceptances/{id}` 查看。

需要撤销时，调用 `POST /api/v1/robots/{robot_id}/acceptances/{id}/revoke` 并填写 reason。重复撤销保留首次审核记录。撤销后新的执行检查不再认可该证据，现场停车使用独立停车入口。

## 必要试验

所有能力均记录停止、急停、失联、人工接管及实际控制发布者检查。不同任务另有独立检查项。

| 能力 | 任务检查 |
|---|---|
| 导航 | 定位、真实到达、取消、障碍停车 |
| 巡检 | 定位、整条路线完成、停留与换站、取消、障碍停车 |
| 运输 | 取件点到达、人工装件、送达点到达、人工交接、中断 |
| 静止搜索 | 静止锁、全程无运动输出、目标确认、过期帧拒绝 |
| 路线搜索 | 路线完成、停留与换站、目标停车、整计划等待人工、搜索恢复、证据保存、过期帧拒绝 |

搜索还需逐目标记录至少十次出现及至少 90% 的成功停车，另有至少 600 秒、零误停车的干扰测试。路线搜索需同时运行导航与视频至少 600 秒，有效识别频率至少 3 Hz，帧龄 P95 不超过 0.5 秒，控制超期无新增。登记核验这些数值及当前模型摘要。

## 已有数据和验证状态

升级保留旧证据，增加撤销字段并记录迁移版本。缺少规范证据的历史记录显示为未验收，不能恢复运动放行。证据摘要不符、被撤销、地图改变、构建改变或模型改变时，对应记录不再放行新任务。

登记是验收人对所留存证据的审核。主机验证格式、版本、计数和门槛，物理试验由现场完成。本轮自动化测试使用隔离模拟数据，验证了越权、陈旧里程计、版本不匹配、重复登记、撤销、旧库升级及搜索指标边界。实际车辆的验收记录仍待采集。
