# 固定朝向横移避障修正

当前车体轮廓 25 × 21 cm，前缘与雷达位置不变，基础缓冲 5 cm。此次修改不继续缩小车身或过滤额外回波。

## 原因与变更

项目为 ROSMASTER X3 麦克纳姆轮底盘，现有手动速度接口支持 linear_y。此前主动绕行却采用差速弧线控制，先旋转车辆，因而后侧近点会通过转向扫掠检查阻止绕行。这与用户期望的横移绕行不同。

现将车端主动绕行默认设为 holonomic：前方触发并由独立扫描确认后，选择安全的一侧，保持朝向横移，再向前通过。所有自动绕行动作 angular_z 为零、不主动后退；保留锁定左右、有效运动意图、45 秒/1.5 米、速度不超过原意图 80% 和 0.25 m/s、松手/停止/目标丢失/搜索命中/急停优先级。朝向漂移超过 0.12 rad 时停车，不在近障旁自动旋转纠正。绕行结束不自动回原车道。

平移扫掠几何存在一个实际错误：dy>0 时原实现对矩形左右两侧同时加宽，虚构了向右侧的扫掠。现分别保留 left/right 边界，仅向移动方向扩展；x 方向同样保留单侧扩展。后侧或另一侧真实点在距离不减小时可允许平移，但身体内部未标定点仍停车。边界接触点可远离或平行离开，不允许倒向墙内。

启动、每周期执行和选边均检查方向对应的平移区域。候选远段只允许延后未知区判断，不延后真实障碍检查。原始雷达点、有限间隙推断、未知区域和传感器超时规则保留；前方观测不足依然可能停车，不能把此修正称为解决了所有缺测。

手动转动与 Nav2 转动仍检查完整旋转扫掠。Nav2 继续提供自己的方向，避障层不把导航速度替换为横移任务。差速候选实现保留用于明确选择 differential 的底盘；本车控制器默认 holonomic，状态中报告 motion_model。车端配置有临时模型路径，部署时保留有效配置而不整体覆盖。

## 验证

101 项相关回归通过，包括尾部接墙前进、倒向墙被阻止、近尾墙横移、靠近侧障被阻止、身体内回波、前后未知区域区分、松手中断、Nav2 方向保留，以及保持朝向的闭环绕行。闭环模拟确认绕过前障、无接触并结束交还控制；模拟结果不等于实车通过。

新增实车记录继续保存在 output/active-avoidance-20261028，按时间命名；发布后核对实际构建标识 avoidance-0.3.11-holonomic-sweep、motion_model=holonomic、文件哈希及最终停止。实车成功标准仍是里程计和现场行为，而不是 API 请求成功或仅有非零输出。

部署后已执行前进和左移短测，最高请求约 0.042 m/s，均未确认实际位移。左移记录 bounded-probe-1793190561284376200.json 显示左侧未知区域（车体坐标约 x=0.037、y=0.137 米）拦截，属于实际靠近方向的观测不足，不是右后侧真实近点拦截。结束均确认停止模式、零速度；本次没有宣称左右绕障实车验收通过。

前进记录 bounded-probe-1793190540203890400.json 出现已放行的 0.042 m/s 输出，里程计为零。随后不加速、最长半秒的补测 bounded-probe-1793190649926914400.json 同样先放行，随后因前左局部未知区域（约 x=0.126、y=0.090 米）归零，所有采样里程计平移速度为零。低速启动能力、传输到电机及局部观测不足尚不能据此分别定责；明确未记录到尾部近点阻止直行。
