# 操作者指定的缺测空旷策略

## 2026-11-02：车体内部回波规则更新

操作者明确要求：车体内部点视为车辆自身，车体外点按缓冲区和运动轨迹判断。当前构建为 `avoidance-0.3.11-body-interior-mask`。控制层按 TF 转换后的车体坐标过滤实测 25×21 厘米矩形严格内部的有效回波，不再要求与历史标定点匹配；矩形边界和外部点保留。过滤范围使用车体本身，不含 5 厘米缓冲区，也不随候选运动轨迹扩大。原始扫描保持不变。

内部回波的遮挡射线仍受既有缺测策略控制：只有健康、完整且来源匹配的扫描，在操作者启用 `assume_clear` 时才按量程假定可见；保守模式下仍为未知。状态 `assumed_clear.body_filter_policy=measured_rectangle_interior`，`body_filtered_rays` 记录过滤数量。车体外障碍、断流、TF/里程计故障、停止和急停检查保留。矩形内部统一归为自身是本次操作者指定的几何假设。

相关 Python 检查 93 项通过，覆盖车体边界、外部缓冲区和 TF 转换后的过滤。实车短测已确认过滤生效，前进输出 0.042 m/s；最长 1.5 秒的短测记录里程计位移约 3.1 厘米，现场操作者确认实际前移，结束为停止模式和零输出。记录位于 `output/vehicle-validation-20261102/`。完整左右绕障、双侧堵塞、移动搜索停车与十分钟联合验收仍需单独验证。

同日继续实测时，发现精确时间的 odom TF 偶尔比扫描晚到约 3.8 毫秒，导致原实现清空仍有效的上一帧。现仅对“向未来外推”异常保留原时限内的上一帧，并在控制周期重试同一时间戳；不改用最新 TF，也不续期旧证据。其他变换异常和原 0.6 秒扫描、0.5 秒里程计时限仍停车。新增两项回归通过，控制适配检查共 10 项通过；部署后记录到一段约 10.3 厘米的连续前移，没有重现该瞬时停车。

前障在约 39 厘米处触发制动。候选原先只有 25、35、45、55、65 厘米横移，漏掉当前扫描中约 13～24 厘米的可行左通道。现增加 15、20 厘米及 5 厘米间隔的候选，仍完整检查两段路径的外部障碍和 5 厘米余量。相关 66 项回归通过；实车已记录向左横移约 3.2 厘米、朝向变化约 0.1°，结束停车。该短测证明选边和横移开始执行，尚不代表完成整段绕障。

操作者随后明确授权最长 35 秒、累计路程上限 85 厘米的一轮低速绕行。该轮约 28 秒完成“左横移—前进通过—交还控制”，累计里程计路程约 83.1 厘米，相对本轮起点前进约 69.7 厘米、左移约 16.1 厘米，最高里程计速度约 0.052 m/s，最终朝向变化约 0.85°。控制输出角速度全程为零，结束确认停止模式、零输出及新鲜静止里程计。现场操作者确认完整绕过、全程无接触，故左侧完整绕障可记为单次通过；右侧及重复性仍待验证。证据见 `output/vehicle-validation-20261102/left-detour-acceptance.json`。

该轮是 manual 模式下持续前进指令触发的避障。视觉服务按现有实现只在 stop/auto/navigation 模式提交推理，manual 期间暂停，故不能据此宣称视觉与避障联合负载通过。未生成移动搜索或联合性能证书。

## 2026-10-28 历史策略与记录

下文保留当时策略和部署边界，其中“仅标定回波可过滤”及“阴影补充尚未部署”的描述已被上述更新取代。

2026-10-28，操作者明确要求“缺测就直接当空旷”。此策略取代先前对相同缺测方向强制等待观测的要求；它是操作假设，不是雷达证明。

车端默认参数 avoidance_assume_missing_clear=true，可在停车后改为 false 并重启以恢复原保守策略。状态 missing_data_policy 报告请求模式与是否生效，assumed_clear 报告本帧假定空旷射线数量、已标定车身遮挡射线数量和距离上限，device_proven=false。界面显示当前策略，原始扫描与有效外部障碍点不修改。

生效前要求扫描时间有效、不超过 0.6 秒，完整视场，来源包与扫描时间戳/索引匹配，来源包健康标记为真，并通过原连续三帧健康门槛（扫描至少 5 Hz、有效距离点比例至少 60%）。缺少对应来源、整帧失效或流中断不提供假定空旷；TF 和里程计故障、停止与急停规则保留。只有健康条件满足后的原始正无穷 unknown/unsampled 格，以及已经通过移车对照标定且仍位于车体内的自身回波阴影按量程范围假定空旷。

NaN、负无穷、显式 invalid/body_occluded、超出有效量程的有限值不按空旷处理。外部真实命中点保留，未标定车体内近点也保留，不能通过扩大自反射过滤放行。

含义：低反射障碍、采样间隙或车身遮挡下漏检的障碍可能无法触发防撞。真实障碍前方或后方的“未看到”不能宣称是已观测空地；此版本明确记录使用操作假设。二维扫描平面之外的物体仍不在已解决能力内。

105 项相关 Python 回归与 108 项前端测试通过。前一阶段板端短测记录 bounded-probe-1793192934313520700.json 中策略生效，前进输出持续 0.042 m/s，没有缺测归零，但没有里程计位移；左移首次仍被标定车身阴影阻止，随后本地按操作者的缺测策略纳入该阴影，仍需部署并复测。软件通过不等于实际移动、左右绕障或视觉搜索停车验收通过。
