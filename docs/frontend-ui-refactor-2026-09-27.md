# InsightRover 前端界面重构记录（2026-09-27）

## 范围与现有架构

本次修改的是 `flutter_app/` 管理端。它使用 Flutter Material 3、Riverpod、go_router、`http`、`web_socket_channel` 和 SharedPreferences。`web-console/` 是另一套 React 小车控制台，本次没有改动。

管理端仍通过 `ApiClient` 和 `OpsRepository` 访问原有 `/api/v1/*` 接口；登录、JWT 刷新、路由权限检查、机器人状态订阅与 WebSocket 重连逻辑没有改协议。演示数据仅在显式开启 `DEMO_MODE` 或从顶部数据来源菜单切换后使用。

## 界面与交互

- 统一浅色工作区主题、深色顶部导航、状态色、间距、圆角和动画时长；全局页面切换采用短时淡入和微位移。
- 登录页改为实验室主视觉与表单分栏，支持记住用户名、密码可见性和提交状态。主视觉使用用户提供的小车照片作为外观参考生成，突出绿色麦克纳姆轮、分层底盘、前置相机及顶部雷达。
- 总览以深色示意地图为中心，右栏并排提供视频状态和机器人状态，下方保留活动流。机器人详情同时提供地图、视频、状态与近期活动。
- 机器人、巡检、运输、异常列表补充搜索或状态过滤；在 1024px 以下切换为先列表后详情，避免三栏内容过窄。
- 地图与路线页采用水平二级导航、资源列表、地图和路线详情。具有 `routes.manage` 权限的用户可对**草稿**路线添加数字坐标航点、调整顺序、删除并通过现有 `PUT /api/v1/routes/{id}` 保存。示意底图未标定，草稿编辑不向机器人下发导航命令。
- 顶部通知入口及用户菜单按照现有权限显示。未接入的视频、未标定地图、缺失的实时指标继续明确标注为不可用，不用演示数据冒充实车数据。

## 实际边界

- 当前项目没有可直接显示的标定 SLAM 地图影像及机器人视频流。地图是明确标注的示意图，视频在未接入网关时显示不可用状态。
- 草稿航点可写入后端路线资源，但尚不能在示意底图上拖动或定位，也不能据此验证实车导航。
- 本次没有实车、ROS2 或网关联机验证。浏览器检查使用的是原数据库的临时副本，未改动原数据库文件。
