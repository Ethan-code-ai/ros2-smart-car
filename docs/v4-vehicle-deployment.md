# v4.0.0 车端部署与静止检查

v4 车端包含机器鉴权、控制代际、三秒执行租约、可靠导航任务和搜索记录。主机与车端需要使用相同的机器凭据。首次启动保持 stop，控制器在没有租约时输出零速度。

部署使用独立目录，校验源码摘要，复用已核对的 ROS Humble 与底盘驱动环境，并单独构建 smart_car_decision。现场设备标定参数从当前部署复制，新增参数保留本版默认值。启动后核对实际模块路径、服务入口和 component_manifest。

共享视觉服务使用本地 yoloe-11s-seg.pt 及 mobileclip_blt.ts，并在工作进程中禁止网络下载。模型和依赖需在部署准备阶段放好。只放入 /dev/shm 的内容会在重启后丢失，现场恢复时应记录实际文件位置、摘要及可用空间。

使用共享视觉服务时，启动参数 start_yolo_camera:=false 关闭独立的旧自动巡航检测进程。其余控制节点与底盘安全链仍由 bringup 启动。

静止检查包括雷达、里程计、TF、相机、视觉模型、停车锁、租约回执和 /cmd_vel 发布者。任何移动结论都需要同步记录请求、实际速度、位移和最终停车。首次静止检查通过后，按 v4-physical-acceptance.md 逐能力完成现场验收。
