# v4.0.0 代码交付状态

按用户最新要求，已停止实车和模型验证，本轮以代码收尾、推送开发分支和打包为交付范围。

新增助手包含真实状态查询、受限Tool Calling、结构化计划、一次确认、持久执行、人工装件交接、目标发现后等待、事件报告、可续传事件流和可拖动桌宠浮窗。模型不能直接发布速度或任意ROS/HTTP命令。

本次补齐move_relative受限前进和管理员单计划现场授权。前进限制为5—20厘米、速度指令上限0.10米/秒、最长4.5秒，复用机器鉴权、租约及独立停车。控制器最终输出也执行前向限幅，拒绝该任务的侧移、后退和转向。现场授权不写入正式能力验收。

本轮优化了执行循环连接复用、失败后重新核验草案、取消时静止检查，以及诊断日志大小限制和写入异常隔离。接口及边界见[v4-agent-control.md](v4-agent-control.md)。

交付文件位于releases/v4.0.0，源码提交、构建清单和文件摘要以release-manifest.json及SHA256SUMS.txt为准。Windows内部版本为4.0.0，对外为v4.0.0，同时提供车端源码包。不会覆盖本机已安装的0.3.11。

从本次提交的源码快照打包，避免带入工作区既有删除项、无关变更、环境文件和用户数据。本轮不再重复功能回归或调用模型，仅执行构建和包内容检查。

历史验证包括111项前端、171项后端和两轮冻结程序检查，均对应此前候选，不能证明最后收尾改动已经通过相同回归。新增控制分支此前28项专项用例通过，最后的控制器限幅及日志保护未重新验证。
